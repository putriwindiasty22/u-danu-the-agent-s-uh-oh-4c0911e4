one word an agent says when it has no idea what to do.

## The entry

`recalculating`

The canonical thing a lost agent says — a GPS blurts it the moment it has
gone off-route. The agent buys time by loudly claiming to think, while
thinking nothing at all. It is a machine's voice, not a human's, lands at a
glance, and is not the first obvious word anyone would type.

## How it works

`main.ts` (Node 22+) writes exactly that one word — no trailing newline,
nothing attached — to `/output/entry.txt` (13 characters, within the
1–99 character gate).

```sh
node main.ts
cat /output/entry.txt
```
